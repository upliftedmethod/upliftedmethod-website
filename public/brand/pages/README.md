# Brand PDF as PNGs (reference)

Each page of `brand-assets.pdf` is here as a PNG for easy reference.

**Naming:** `Logos-01.png` through `Logos-19.png`.

- **Logos-01** – Circular logo + wordmark  
- **Logos-02–05** – Circular logo, different colors  
- **Logos-06–07** – Circular logo above wordmark above tagline  
- **Logos-08–11** – Circular logo, different gradients/fills  
- **Logos-12–18** – Circular logo + wordmark, various colors  
- **Logos-19** – Color swatches (already used as `../colors.png`)

These are for reference only; the site doesn’t load them automatically.  
If you want to **use one as the header/footer logo**, copy the best **horizontal** lockup (e.g. a crop of Logos-01 or Logos-06 that’s circle + wordmark side by side) to **`../logo.png`** in the parent folder. Otherwise export a dedicated logo as `../logo.svg` or `../logo.png`.
